# Atividade desafio sobre estrutura de árvores 

**Disciplina:** Estruturas de Dados II
**Tema:** Design de Jogos Educativos sobre Árvores Avançadas por meio da Engenharia Reversa e Reuso de Modelos

Proposta de upgrade pedagógico do módulo **Binary Search Tree / AVL Tree** do
[VisuAlgo](https://visualgo.net/en/avl), transformando a visualização passiva de
rotações AVL em uma mecânica de jogo ativa, na qual o jogador diagnostica o
desequilíbrio e escolhe a rotação correta (LL, RR, LR ou RL).
